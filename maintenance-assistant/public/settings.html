Only Cosmos DB for NoSQL is supported. Other engines (SQL, MongoDB, ...) would need their own connector. Work order status changes assume the WorkOrders container is partitioned by /status.

AI model (Azure OpenAI)

Without an AI model the system uses rule-based decisions. With one, the model proposes diagnosis and dispatch, and the code validates every choice.
